# Issue tracker: GitHub

Issues and PRDs for this repo live in GitHub Issues at `arjayby/aeri-ui`. Use the `gh` CLI for issue operations and infer the repository from the local Git remote.

## Conventions

- Create, read, comment on, label, and close work through GitHub Issues.
- When a skill says to publish to the issue tracker, create a GitHub issue.
- When a skill says to fetch a ticket, read the issue and its comments and labels.
- Pull requests are not a request or triage surface.
