# Aeri UI Catalog Structure

## Primary collections

The Catalog separates Registry Items into Components and Blocks.

## Functional categories

Items are grouped by product purpose rather than animation mechanism:

- Actions
- Forms
- Navigation
- Overlays
- Feedback
- Data Display
- Content

## Filters

Builders can filter items by:

- Native motion or `motion` dependency
- Server compatibility or client boundary
- Base UI dependency
- Lifecycle status
- Recent publication

## Search

One search experience covers Components, Blocks, and documentation. Motion techniques remain searchable metadata but do not define the primary navigation.
