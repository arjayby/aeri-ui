# Aeri UI Launch Set

The first public release contains eight Components and three Blocks. Every item must satisfy the Registry Item Performance Contract, accessibility requirements, reduced-motion behavior, documentation standards, mobile behavior, and installation verification before publication.

## Components

1. **Button** — press feedback and async state transitions.
2. **Tabs** — moving active indicator and directional panel transitions.
3. **Accordion** — measured expansion with restrained easing.
4. **Switch** — tactile thumb and press response.
5. **Tooltip** — subtle focus and hover presence transitions.
6. **Input** — focus, validation, and success feedback.
7. **Number Ticker** — accessible numeric value transitions.
8. **Text Swap** — keyed label or status transitions without layout jumping.

## Blocks

1. **Command Palette** — keyboard-first search, grouped results, a moving active row, an empty state, and action callbacks.
2. **File Upload** — drag and drop, validation, progress, retry, cancellation, and success or error transitions through consumer-provided callbacks.
3. **Settings Form** — composed Inputs, Switches, and Buttons with dirty, saving, saved, validation, and failure states.

Blocks do not require a particular backend, authentication service, or form library.
