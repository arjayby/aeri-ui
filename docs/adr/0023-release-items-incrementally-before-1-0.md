# Release items incrementally before 1.0

Aeri UI may publish completed Registry Items through `0.x` preview releases while the Launch Set is being built, provided each preview item passes its applicable accessibility, performance, installation, and documentation gates. A stable 1.0 release requires all eleven Launch Set items, the unified Catalog, the complete four-package-manager release matrix, and the public `@aeri-ui` Registry Directory listing. After 1.0, unfinished work remains in pull-request previews rather than the canonical registry.
