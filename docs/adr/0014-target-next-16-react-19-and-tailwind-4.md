# Target Next.js 16, React 19, and Tailwind CSS 4 in v1

Aeri UI v1 will guarantee Registry Items in TypeScript for Next.js 16 App Router Consumer Projects using React 19, Tailwind CSS 4, shadcn, and Base UI in current evergreen browsers. Items will preserve Server Component rendering and use the smallest practical client boundary, while React-only Components should avoid Next.js APIs when feasible. V1 will not guarantee Pages Router, React 18, Tailwind CSS 3, Radix, React Aria, JavaScript-only projects, or legacy browsers.
