# Require WCAG 2.2 Level AA before publication

The Aeri UI catalog and every Registry Item will satisfy all applicable WCAG 2.2 Level A and Level AA criteria before publication. Verification will combine automated checks with manual keyboard, focus, screen-reader, zoom, reflow, non-drag alternative, reduced-motion, and status-announcement testing. Aeri UI will not advertise formal site-wide conformance until the complete public experience has been audited, but item documentation may report the applicable criteria verified in its fixtures.
