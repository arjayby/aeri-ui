# Require the `@aeri-ui` directory listing for 1.0

Development and preview releases may expose Registry Items through direct URLs or explicit `components.json` namespace configuration, but Aeri UI will not declare a stable 1.0 release until shadcn's public Registry Directory resolves `@aeri-ui` automatically. The four package-manager forms of `shadcn add @aeri-ui/<item>` are part of the stable installation contract and must work without prior project configuration.
