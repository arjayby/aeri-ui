# Provide Live Previews without an embedded IDE

Every Item Page will render the Registry Item's installable source in an interactive Live Preview and expose relevant controls for state, props, Consumer Theme, reduced motion, and viewport size. Source and installation commands will be copyable, and complex cases may link to an external sandbox. V1 will not include an embedded code editor, arbitrary code execution, dependency installation, or saved playgrounds, avoiding the weight and security surface of a browser development environment.
