# Keep v1 English-only and Registry Items localization-ready

The v1 Catalog and documentation will be written in English without shipping translation infrastructure. Registry Items must avoid hardcoded essential copy, expose Block labels and messages for local configuration, use logical layout properties where direction matters, and make directional motion follow the Consumer Project's text direction. Direction-sensitive items will be verified in an RTL fixture while Base UI provides the underlying bidirectional keyboard behavior.
