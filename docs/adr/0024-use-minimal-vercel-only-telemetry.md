# Use minimal Vercel-only telemetry

Aeri UI will use sampled Vercel Speed Insights to validate real-world Core Web Vitals and basic Vercel Web Analytics for aggregate Catalog traffic, accompanied by a clear privacy notice. V1 will not add custom behavioral events, Google Analytics, advertising pixels, session replay, user profiling, or cross-site tracking. Telemetry scripts are optional enhancements: blocking or failing them must not affect the Catalog, documentation, search, Live Previews, or registry delivery.
