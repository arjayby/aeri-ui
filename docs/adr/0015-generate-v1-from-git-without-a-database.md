# Generate v1 from Git without a database

Aeri UI v1 will treat the repository as the source for Registry Items, metadata, documentation, examples, and search content, generating the Catalog and registry payloads at build time. GitHub issues and pull requests will handle feedback and contributions. V1 will not require user accounts, a database, an application API, a headless CMS, saved favorites, or cloud playground persistence; optional anonymous analytics must not be required for the product to function.
