# Operate a curated registry

Aeri UI will operate a maintainer-owned Curated Registry rather than an open marketplace. External contributors may propose fixes, documentation, Components, and Blocks through pull requests, but publication requires editorial approval and satisfaction of the same API, accessibility, performance, documentation, and visual standards as maintainer-authored work. V1 will not include user accounts, a submission database, automatic third-party publication, or arbitrary external registry listings.
