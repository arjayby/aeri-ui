# Forbid Installed Source from calling home

Registry Items will contain no Aeri UI analytics, update or license checks, advertising, telemetry, or required requests to `aeriui.dev`, and will not depend on externally hosted fonts, images, scripts, or CDN assets. Network behavior is permitted only when intrinsic to a Block and explicitly supplied by the Builder through callbacks or endpoints. Installed Source must remain functional offline and if Aeri UI infrastructure ceases to exist.
