# Embed Fumadocs as the content engine

The unified `apps/web` application will use Fumadocs Core and Fumadocs MDX for documentation content, navigation metadata, and search while presenting a custom Aeri UI documentation shell. The standalone `apps/fumadocs` application and its stock UI shell will be removed after their useful configuration and content are migrated. This preserves mature documentation infrastructure without splitting the public product or surrendering Aeri UI's performance and visual constraints.
