# Aeri UI Privacy Notice

## Scope

This notice covers the public Aeri UI Catalog at `aeriui.dev`, including its documentation, search, and Registry delivery. Aeri UI does not provide accounts, forms that require personal details, or a database of Catalog visitors.

## Limited telemetry

Vercel deployments use only the approved aggregate Vercel services: sampled Vercel Speed Insights for Core Web Vitals and Vercel Web Analytics for aggregate traffic measurement. These services help maintain Catalog reliability and performance.

We do not use session replay, advertising pixels, user profiling, cross site tracking, or custom behavioral event collection. Catalog functionality does not depend on telemetry. If telemetry fails or is blocked, the Catalog, documentation, search, Live Previews, and Registry delivery continue to work.

Vercel processes telemetry from these services under its own [privacy policy](https://vercel.com/legal/privacy-policy). GitHub processes repository contributions, issues, and security reports under its own privacy terms.

## Contact and changes

If this notice changes materially, the update will be made in this file and published with the corresponding repository change. Questions about this notice can be opened as a public GitHub issue only when they do not contain sensitive information.
