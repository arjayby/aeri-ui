Aeri UI is a permanently public, free, MIT licensed Curated Registry of installable interface source. The personal GitHub repository at [github.com/arjayby/aeri-ui](https://github.com/arjayby/aeri-ui) is the canonical project record.

## Editorial publication

External contributions are welcome, but the Registry is not an automatic publishing system. A maintainer makes the final editorial decision for every Registry Item after it passes the applicable API, accessibility, motion, performance, documentation, compatibility, and installation contracts.

External contributors submit a proposal before implementing a new item. This records the Builder need, proposed public API, dependencies, accessibility considerations, motion behavior, and performance cost. It gives the project a useful review point before implementation begins.

## Maintainer accountability

Maintainer authored Registry Items do not require a public proposal. They still record the same rationale in their colocated item record and pass every quality gate. This keeps standards consistent regardless of authorship.

## Open source commitments

Published Registry Items remain free to use and MIT licensed. The Catalog does not divide Registry Items into free and paid tiers. Any future commercial work must remain separate and cannot remove, cripple, or relicense previously published Registry Items.

For the contribution process, read [Contributing to Aeri UI](./contributing). For sensitive reports, use the [Security Policy](./security).
