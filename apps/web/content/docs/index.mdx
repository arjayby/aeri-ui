Aeri UI is a Curated Registry of polished interface source for production applications. It is designed for Builders who want considered interaction quality without adding a design system runtime to their Consumer Project.

## What is Aeri UI?

Aeri UI provides focused Components and Blocks for existing Next.js and shadcn Consumer Projects. Every Registry Item is selected, documented, and tested as part of one coherent Catalog.

The complete Launch Set contains eight Components and three Blocks. Every current Registry Item remains a Preview Item until the stable 1.0 release gates are complete.

## How the registry works

Install a Registry Item with the shadcn CLI:

```bash
npx shadcn@latest add @aeri-ui/button
```

During Registry Directory review, configure the `@aeri-ui` namespace or install a direct registry URL. Read the [1.0 release candidate](/docs/release-candidate) for the current commands and release status.

The command places the complete Installed Source in your Consumer Project. There is no Aeri UI runtime package to keep synchronized.

## You own the source

Installed Source lives in your repository from day one. Read it, restyle it, version it, or reshape its API to suit your product. Updates remain explicit, so upstream changes never arrive without your review.

Components inherit the Consumer Project's semantic colors, typography, radius, dark mode, and direction through the Consumer Theme.

## Supported stack

The first release targets Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn, and Base UI in current evergreen browsers.
