Aeri UI is a curated registry of polished interface source for production applications. It is designed for builders who want considered interaction quality without adding a design system runtime to their project.

## What is Aeri UI?

Aeri UI provides focused Components and Blocks for existing Next.js and shadcn applications. Every item is selected, documented, and tested as part of one coherent catalog.

The collection begins with Button and will grow incrementally. A smaller catalog keeps every published item accountable for accessibility, performance, responsive behavior, and maintenance quality.

## How the registry works

Install an item with the shadcn CLI:

```bash
npx shadcn@latest add @aeri-ui/button
```

The command places the complete source in your application. There is no Aeri UI runtime package to keep synchronized.

## You own the source

Installed source lives in your repository from day one. Read it, restyle it, version it, or reshape its API to suit your product. Updates remain explicit, so upstream changes never arrive without your review.

Components inherit the consumer project's semantic colors, typography, radius, dark mode, and direction rather than bringing a separate Aeri theme with them.

## Supported stack

The first release targets Next.js 16, React 19, TypeScript, Tailwind CSS 4, shadcn, and Base UI in current evergreen browsers.
