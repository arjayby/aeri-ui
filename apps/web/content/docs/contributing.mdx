Aeri UI is a public, MIT licensed [Curated Registry](./governance). Its canonical repository is [github.com/arjayby/aeri-ui](https://github.com/arjayby/aeri-ui).

## Propose a Registry Item

External contributors propose a new Component or Block before implementation. The [Registry Item proposal](https://github.com/arjayby/aeri-ui/issues/new?template=registry-item-proposal.yml) records the Builder need, intended interaction, public API, dependencies, accessibility considerations, motion approach, and performance cost.

Maintainers review proposals for user need, overlap with existing shadcn and Aeri UI source, and fit with the Catalog. Approval permits implementation work but does not guarantee publication.

## Publication contracts

Every Registry Item must meet the applicable API, accessibility, motion, performance, documentation, compatibility, and installation contracts. Publication in the Curated Registry remains an editorial maintainer decision after those checks pass.

For changes that do not introduce a Registry Item, open a focused pull request with the behavior it changes and the checks you ran. Contributions are accepted under the repository's [MIT License](https://github.com/arjayby/aeri-ui/blob/main/LICENSE).

## Maintainer authored items

Maintainers may create a Registry Item without a public proposal. The item still records the same Builder rationale in its colocated record and passes every quality gate before publication.

Read the complete repository guidance in [CONTRIBUTING.md](https://github.com/arjayby/aeri-ui/blob/main/CONTRIBUTING.md).
