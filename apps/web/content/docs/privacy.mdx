This notice covers the public Aeri UI Catalog, including documentation, search, and Registry delivery.

## Limited aggregate telemetry

Vercel deployments use only sampled Vercel Speed Insights for Core Web Vitals and Vercel Web Analytics for aggregate traffic measurement. These approved services help maintain Catalog reliability and performance.

The Catalog does not use session replay, advertising pixels, user profiling, cross site tracking, or custom behavioral event collection. Its documentation, search, Live Previews, and Registry delivery continue to work when telemetry is unavailable or blocked.

Vercel processes data from these services under its [privacy policy](https://vercel.com/legal/privacy-policy). GitHub processes repository contributions, issues, and security reports under its own privacy terms.

Read the complete repository notice in [PRIVACY.md](https://github.com/arjayby/aeri-ui/blob/main/PRIVACY.md).
