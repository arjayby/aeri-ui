---
title: Security Policy
description: Privately report vulnerabilities and follow coordinated disclosure through GitHub Security Advisories.
---

Do not submit sensitive vulnerability details through public issues, pull requests, discussions, Catalog forms, or analytics.

## Private reporting

Use GitHub private vulnerability reporting from the [Aeri UI Security Advisories page](https://github.com/arjayby/aeri-ui/security/advisories). Select **Report a vulnerability** and include the affected source or route, a reproduction, impact, and any suggested mitigation.

## Coordinated disclosure

Maintainers review and validate reports privately, collaborate on a fix, and use a GitHub Security Advisory to coordinate publication. A public disclosure follows a patched release whenever practical, with migration guidance when Builders need to take action.

Current Stable Registry Items and actively used Deprecated Registry Items receive security fixes. Give maintainers reasonable time to investigate and release a fix before public disclosure.

The complete repository policy is available in [SECURITY.md](https://github.com/arjayby/aeri-ui/blob/main/SECURITY.md).
