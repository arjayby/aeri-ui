# Security Policy

## Reporting a vulnerability

Do not report suspected vulnerabilities in public issues, pull requests, discussions, Catalog forms, or analytics.

Use GitHub private vulnerability reporting for [arjayby/aeri-ui](https://github.com/arjayby/aeri-ui/security/advisories). Select **Report a vulnerability** and include a clear description, affected source or route, reproduction steps, impact, and any suggested mitigation. This private channel is the only place for sensitive report details.

## Coordinated disclosure

We review reports privately, work with the reporter on validation and a fix, and use a GitHub Security Advisory to coordinate publication. Public disclosure follows a patched release whenever practical. Advisories include migration guidance when a fix requires Builder action.

Current Stable Registry Items and actively used Deprecated Registry Items receive security fixes. Please give maintainers reasonable time to investigate and prepare a coordinated advisory before disclosing details publicly.
